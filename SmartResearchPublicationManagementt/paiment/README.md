# Site de paiement (localhost)

## Lancer le site

Option 1 (Node.js) :

1. Installer Node.js
2. Ouvrir un terminal dans ce dossier
3. Executer :

```bash
node server.js
```

4. Ouvrir : <http://localhost:3000>

Option 2 (sans Node.js, via Python) :

```bash
cd public
python -m http.server 3000
```

Puis ouvrir : <http://localhost:3000>
